# 원스톱 툴

## 포함 기능
- 근무시간 계산기
- 날짜·D-day 계산기
- 이미지 용량 줄이기
- 소개/개인정보처리방침/이용약관/문의
- robots.txt / sitemap.xml / ads.txt / CNAME

## GitHub Pages
1. 이 폴더의 파일과 폴더를 저장소 최상위(root)에 업로드합니다.
2. Settings > Pages > Deploy from a branch
3. Branch: main / Folder: /(root)

## 도메인을 아직 구매하지 않았다면
초기 GitHub Pages 테스트 전에 `CNAME` 파일을 삭제하거나 `CNAME.txt`로 바꾸세요. 도메인 구매 후 다시 사용하면 됩니다.

## AdSense 연결 후
- 각 HTML의 head에 있는 AdSense 주석에서 ca-pub 값을 본인 것으로 교체
- ads.txt를 AdSense에서 제공하는 본인 라인으로 교체
- 화면의 점선 AdSense 광고 영역을 실제 광고 단위로 교체

## 문의 이메일
contact.html의 `your-email@example.com`을 실제 주소로 교체하세요.
